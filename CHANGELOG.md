# Changelog

All notable changes to Reading List. Format roughly follows
[Keep a Changelog](https://keepachangelog.com). The most recent release is at
the top. Each entry is consumed verbatim by the release pipeline and shown to
users on the app's detail screen in the Groom Hub.

## v0.1.0 — Initial release

Search Open Library, save books to read, and have them filed into genre
sections automatically. Up Next queue, read shelf with ratings and stats, and
a note on every book for where the recommendation came from.
